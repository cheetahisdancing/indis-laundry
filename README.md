# 인디스 · 세탁실 대기시간 앱 (SwiftUI 프로토타입)

기숙사 세탁실의 현재 상황(사용 가능 / 사용 중 / 곧 끝남 / 수거 대기 / 고장)과 남은 시간을 보여주는 iPhone 앱 프로토타입입니다.
지금은 **예시 데이터**로 동작하고 시간이 실제로 흘러가요. 실제 세탁기 연동은 아직 없습니다.

## 실행 방법 (Mac 필요)

1. Mac에 **Xcode 16 이상**을 설치합니다. (App Store)
2. `Indis.xcodeproj`를 더블클릭해서 엽니다.
3. 위쪽 기기 선택에서 **iPhone 16** 같은 시뮬레이터를 고릅니다.
4. **⌘R** (또는 ▶ 버튼)을 누르면 시뮬레이터에서 앱이 실행돼요.

- 시뮬레이터 실행에는 Apple 개발자 계정이 필요 없습니다.
- 실제 iPhone에 설치하려면 `Signing & Capabilities`에서 본인 Apple ID 팀을 고르세요.
- 코드만 보고 싶으면 `HomeView.swift`를 열고 오른쪽 **Canvas**(Preview)를 켜도 됩니다.

## Mac 없이 실행하기 (Windows 브라우저)

1. GitHub에 새 저장소를 만들고 이 폴더 전체를 올립니다. (`.github` 폴더 포함 / **공개 저장소면 무료**)
2. 올리면 `Actions` 탭에서 **iOS Simulator Build**가 자동으로 돌아갑니다. (5~10분)
   - 초록 체크 = 빌드 성공. 빨간 X면 로그의 오류 메시지를 확인하세요.
3. 끝난 실행을 눌러 아래 **Artifacts**에서 `Indis-simulator`를 받습니다. 받은 zip 안에 `Indis-simulator.zip`이 들어 있어요. 이 안쪽 zip을 씁니다.
4. [appetize.io](https://appetize.io)에 가입하고 `Indis-simulator.zip`을 업로드하면, 브라우저에서 iPhone 화면으로 앱을 직접 눌러볼 수 있어요. 공유 링크로 팀원·사용자 테스트에도 쓸 수 있습니다. (무료 플랜은 사용 시간 제한이 있어요)

## 시연 시나리오 (사용자 테스트용)

건물: 생활관 1~10동, 여사 1~3동. 건물마다 1~3층, 층마다 세탁기 2대(세탁기1·2) + 건조기 1대.
세탁 코스: 강력 45분 · 표준 40분 · 합성 42분 · 울 43분 (건조기는 표준 건조 50분, 시연용 데모 1분 코스 별도)

| 해 볼 것 | 방법 | 확인할 점 |
| --- | --- | --- |
| 세탁실 현황 보기 | 앱 실행 | 층별로 기기 상태·코스·남은 시간이 1초마다 갱신, 작동 중인 기기는 드럼이 회전 |
| 기숙사 바꾸기 | 상단 `생활관 1동 세탁실 · 변경` | 건물마다 다른 현황 |
| 세탁 시작 | 사용 가능한 세탁기 → 코스 선택 (`데모 · 1분`이면 1분 뒤 끝남) | 코스 이름 표시, 드럼 회전, 끝나면 `수거 대기` |
| 끝나면 알림 | 사용 중인 기기 → `끝나면 알림 받기` | 끝나는 시각에 알림 배너 |
| 주인에게 알림 | `3분 초과` 표시가 붙은 기기(모든 건물의 `2층 세탁기2`) → `세탁물 주인에게 알림 보내기` | 주인이 받을 알림이 이 기기에 표시됨, 1분 동안 다시 못 보냄 |
| 빨래 꺼내기 | `수거 대기` 기기 → `빨래 꺼냈어요` | `사용 가능`으로 바뀜 |
| 즐겨찾기 | 기기 상세 → 왼쪽 위 별 | 홈 맨 위 `즐겨찾는 기기`에 건물 이름과 함께 실시간 상태 표시 (다른 동을 보고 있어도 보임, 앱을 다시 켜도 유지) |
| 빈 세탁기 알림 | 하단 `빈 세탁기 생기면 알림 받기` | 보고 있는 건물에 세탁기가 비면 알림 |
| 고장 신고 | 기기 상세 → `고장 신고` | 회색 `고장` 타일로 바뀜 |

- 끝난 지 3분이 안 된 기기는 남은 대기 시간이 표시되고, 3분이 지나면 주인 알림 버튼이 열려요.
- 다른 사람 빨래는 수거 대기 8분이 지나면 "누군가 꺼내 간 것"으로 자동 처리돼요. 내가 넣은 빨래는 자동으로 비워지지 않아요.
- 실제 서비스에서는 주인 알림이 서버를 거쳐 주인 휴대폰으로 가야 해요. 프로토타입에서는 그 알림을 이 기기에 대신 띄워요.

## 파일 구조

```
Indis.xcodeproj           Xcode 프로젝트
Indis/
  IndisApp.swift           앱 시작점
  Models.swift             기기·상태·코스 모델, 남은 시간 계산
  LaundryStore.swift       앱 상태 + 1초 타이머 + 예시 데이터 (실제 서버 연결 시 여기만 교체)
  NotificationManager.swift 로컬 알림
  Theme.swift              색, 상태별 색/아이콘, 아이콘 뷰
  HomeView.swift           홈 화면 (세탁실 현황)
  MachineCard.swift        기기 카드
  MachineDetailView.swift  기기 상세 (남은 시간 링, 버튼)
  Assets.xcassets          디자인한 아이콘(SVG 13개), 앱 아이콘, 강조색
```

## 바꾸기 쉬운 곳

- 기숙사 이름: `LaundryStore.swift`의 `init()`
- 기기 구성·처음 상태: `LaundryStore.swift`의 `sampleMachines`
- '곧 끝남' 기준(5분)·주인 알림 기준(3분)·코스 시간: `Models.swift`
- 색: `Theme.swift`

## 참고

- iOS 17 이상, Swift 5 모드.
- 이 프로젝트는 Mac 없이 작성돼서 아직 한 번도 빌드해 보지 않았어요. 처음 열었을 때 오류가 나면 오류 메시지를 그대로 알려 주세요.
